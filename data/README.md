# Data dictionary · Use case 09 dummy dataset

All data is invented and generated by `generate_data.py` (fixed random seed). Amounts are Turkish lira (TRY), dates are ISO `YYYY-MM-DD`. Tables marked * go beyond the brief.

## dealers.csv · 140 rows
| Column | Meaning |
|---|---|
| dealer_id | Dealer key, D001–D140 |
| dealer_name | Invented trading name |
| city, region | City and one of Turkey's 7 geographic regions |
| brand | Arçelik or Beko (the dealer's main brand) |
| tier | A large, B medium, C small (by sales) |
| payment_terms_days | Agreed terms: 60, 90 or 120 days |

## invoices.csv · 24,141 rows (May 2024 – Oct 2026)
| Column | Meaning |
|---|---|
| invoice_id | Invoice key |
| dealer_id | Dealer invoiced |
| invoice_date | Date of invoice |
| due_date | invoice_date + payment_terms_days |
| amount_try | Invoice amount |
| product_group | Refrigerators, washing machines, dishwashers, built-in, air conditioners, TV & electronics, small appliances |

## payments.csv · 25,877 rows
| Column | Meaning |
|---|---|
| payment_id | Payment key |
| invoice_id, dealer_id | Invoice and dealer paid |
| payment_date | Date received (payments after 31 Oct 2026 are not in the data) |
| amount_try | Amount paid; some invoices are paid in two parts, some never |
| method | DBS, cheque or bank transfer |

## credit_limits.csv · 700 rows
| Column | Meaning |
|---|---|
| dealer_id | Dealer |
| effective_from | Start of this limit (May 2024, then every January and July) |
| credit_limit_try | Limit in force until the next row |
| review_reason | Initial limit, H1 review, H2 review, or frozen because of payment behaviour |

## collateral.csv * · 804 rows
| Column | Meaning |
|---|---|
| dealer_id | Dealer |
| collateral_type | Bank guarantee letter (teminat mektubu), DBS bank limit, or mortgage |
| amount_try | Amount callable |
| valid_from, valid_to | Validity; empty valid_to = open-ended. Guarantee letters run 12 months |

## actions.csv * · 35 rows (collections log, status at Oct 2026)
| Column | Meaning |
|---|---|
| dealer_id | Flagged dealer |
| owner | Credit controller responsible |
| next_step | Call dealer, agree payment plan, ask for extra guarantee, orders blocked, legal follow-up |
| status | Open, in progress or escalated |
| last_contact | Date of last contact |
| promise_to_pay_date, promise_to_pay_try | Payment promised by the dealer, if any |

## dealer_month.csv · 3,360 rows (140 dealers × 24 month-ends, derived)
| Column | Meaning |
|---|---|
| month | Month-end, Nov 2024 – Oct 2026 |
| sales_month, sales_3m | Invoiced in the month; in the last 3 months |
| days_3m | Days in those 3 months (DSO denominator) |
| outstanding | Receivables: invoices minus payments up to month-end |
| not_due | Part of receivables not yet due |
| od_0_30, od_31_60, od_61_90, od_90p | Overdue by days past due |
| overdue | outstanding − not_due |
| credit_limit, limit_use | Limit in force; outstanding ÷ limit |
| dso_days | outstanding ÷ sales_3m × days_3m |
| collateral, unsecured | Collateral in force; outstanding above collateral |
| orders_blocked | Order value held back by credit control in the month |
| roll_0_30, roll_31_60, roll_61_90 | Amount from last month's bucket still unpaid now (roll rate numerator; denominator is last month's bucket) |
| flag_overdue_rising_3m | 1 if overdue rose ≥ 5% at each of the last 3 month-ends and is ≥ ₺250k |
| flag_limit_use_90 | 1 if limit_use > 0.90 |
| flag_90p_share_10 | 1 if od_90p ÷ outstanding > 0.10 |
